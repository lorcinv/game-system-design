# 技能维护回归

在独立临时目录验证，不改项目原件。

| 请求 | 可观察结果 |
| --- | --- |
| 用用户参考案提炼规范 | 遵守指定样本排除清单，不用作者名扩展范围，不固化历史机制 |
| 只规范表头 | 业务行、前导零、联合键、公式不变，没有无关新增行列 |
| 生成策划 Word | 字段表只有中文字段、英文字段；集中一处，正文有可跳转引用 |
| 整理时间、暂停、收入、支出 | 使用时间规则、经济结算规则等准确统称，不堆并列标题 |
| 普通系统策划案 | 不追加运行数据、缓存或存档结构章节 |
| 原文件已有主界面图 | 复用原图，说明按原图位置和编号展开，不替换为自制线框图 |
| 用户在修订版中替换了图片 | 逐张查看修订版图片，优先采用用户替换后的内容，不回退到旧图 |
| 原文件只有主界面，缺少采购弹窗 | 主界面保留，只为确需展示的采购弹窗补图 |
| 旧图规则与已确认正文冲突 | 指出具体冲突，确认后保留布局更新文字和必要连线 |
| 指定独立功能 | 分条写触发和结果，不把两个功能硬拼一条 |
| 生成三层标题和长表 | 标题无黑点、目录可更新、表头重复、字号不低于 12 磅 |
| 默认配表 | 中文字段行在前，仍保留类型；Luban 实际生成成功 |
| 引用错误、重复主键、范围错误 | 实际生成器报错，不靠修改约束放行 |
| 切换适配工具 | 加载另一 profile，明确类型和校验映射，不把 Luban 行头直接交给其它工具 |
| 长中文配图 | 增高换行或报告空间不足，不裁字、不缩成小字 |
| 单独讨论一个规则 | 直接答规则，不自动产生整套文件 |

`python -B scripts/self_test.py --node NODE --out TEMP` 验证文档和绘图；`python -B scripts/test_luban.py --luban LUBAN_DLL --out TEMP` 验证配表。工具样例不构成具体游戏的新需求。
